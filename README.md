## 🤖 بناء APK أوتوماتيك بـ GitHub Actions (بلا كمبيوتر)

المشروع فيه ملف `.github/workflows/build.yml` جاهز. كي ترفع الكود لـ GitHub:

1. `git push` (كيما فالخطوات تحت)
2. روح لتبويب **Actions** فصفحة الـ repository تعك فـ GitHub
3. استنى الـ workflow "Build Android APK" يخدم (يوخذ بين 5 و10 دقايق)
4. كي يكمل بلا أخطاء (✅ باللون الأخضر)، دوس عليه، تلقى تحت **Artifacts** ملف اسمو `CabaPhoneSold-apk`
5. حملو (zip)، فكو، تلقى فيه `app-debug.apk`
6. حولو لتيليفونك ونصبو مباشرة (خاصك تفعل "السماح بمصادر غير معروفة" فإعدادات الأندرويد)

هذا هو بالضبط نفس المبدأ لي درتيه فالمشروع لي فات — بلا ما تحتاج تثبت npm ولا Expo فكمبيوترك.

> ملاحظة: الـ APK لي يطلع هنا هو نسخة "debug" (موقعة أوتوماتيك بمفتاح تجريبي) — تتنصب وتخدم عادي، لكن ماشي مناسبة للنشر فـ Google Play (لهاذيك لازم توقيع "release" حقيقي).

## 🚀 كيفاش تخدم بيه (أول مرة)

خاصك عندك مثبتين:
- [Node.js](https://nodejs.org) (نسخة 18 ولا أكثر)
- تطبيق **Expo Go** فتيليفونك (Android/iOS) — باش تجرب التطبيق بلا ما تبني APK

```bash
npm install
npx expo start
```

يطلعلك QR code، تسكانيه بـ Expo Go فتيليفونك، ويبدا التطبيق يخدم مباشرة.
